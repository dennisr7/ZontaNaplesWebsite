## About the software

A full-stack web application for a service club:

- **Frontend:** React 19 + Vite + Tailwind CSS (`frontend/`)
- **Backend:** Node.js + Express 5 + MongoDB REST API (`backend/`)
- **Integrations:** Stripe payments, Cloudinary uploads, SMTP email

Features: membership applications and dues, scholarship listings and applications, events and RSVPs, donations, a merchandise shop, a contact form, and an admin dashboard.
